# logSW_classification (第一课作业)

## 项目简介
本项目使用 Python 和 Pandas 对 SweetpredDB 数据集进行甜度（logSW）分类分析，并生成饼图。

## 文件说明
- `logsw_classification.py`: 核心 Python 脚本。
- `result_analysis.ipynb`: Jupyter Notebook，包含代码运行结果及图表展示。
- `SweetpredDB.csv`: 原始数据文件。

## 环境依赖 (可复现)
- Python 3.14 
- 依赖库：pandas, matplotlib
